# Model Compression for Super Resolution

This project improves low-resolution images using deep learning models (SRCNN, FSRCNN).

## Key Points
- Implemented CNN-based super resolution models
- Used PyTorch for training
- Applied quantization and ONNX for optimization
- Evaluated using PSNR and SSIM metrics

## Dataset
- FFHQ
- Screen image dataset

## Result
Improved image clarity and reduced blur in low-resolution images.
